# 📊 E-Commerce Sales & Returns Analysis (End-to-End Project)

## 📌 Project Overview
This isn't just a basic Excel chart! I built this project from the ground up, starting with **Raw Data Creation in SQL** and finishing with an **Interactive Dashboard in Excel**. 
This project demonstrates my ability to handle the entire data pipeline: Database Management -> Data Extraction -> Visualization.

## 🛠️ Technical Skills Used
* **SQL:** Designed and created custom database tables in SQL++ with specific constraints to ensure data integrity and connected to dataset to Excel for analysis, handled data entry, and performed data cleaning.
* **Excel:** Connected SQL data to Excel, used Pivot Tables, Advanced Formulas, and Interactive Slicers.
* **Data Visualization:** Built a user-friendly dashboard to track Sales vs. Returns.

## 🚀 Key Highlights
* **Custom Database:** Unlike downloaded datasets, I manually architected the SQL tables to simulate real-world e-commerce scenarios.
* **Interactive Slicers:** Users can toggle between "Returned" and "Not Returned" status to see instant updates on the charts.
* **Actionable Insights:** The dashboard helps in identifying which product categories have the highest return rates.
